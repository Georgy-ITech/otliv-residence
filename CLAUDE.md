# CLAUDE.md — ЖК «Отлив», концепция «Горизонт»

Дополняет `PORTFOLIO/CLAUDE.md`. При расхождении с `DESIGN.md` прав этот файл
(`DESIGN.md` описывает отменённое направление «Премиум-кино»).

## Идея

Одна линия горизонта проходит через весь сайт и меняет роль: граница моря и
неба → высота взгляда в «Виде из окна» → этажная шкала фасада → график платежа →
маршрут на карте → отметка готовности стройки. Каждая секция должна отвечать на
вопрос «чем здесь стала линия». Если ничем — секция не доделана.

## Палитра (токены в `:root`, без хардкода в компонентах)

| Токен | HEX | Роль |
|---|---|---|
| `--dusk` | `#1B2329` | фон по умолчанию, сумерки над заливом |
| `--dusk-2` | `#232D34` | приподнятые плоскости |
| `--concrete` | `#C9C5BC` | бетон, светлые секции-листы |
| `--white` | `#F2EEE6` | основной текст на тёмном |
| `--bay` | `#3E5C6B` | залив, вторичные плоскости |
| `--fog` | `#8FA3AC` | вторичный текст на тёмном (≥ 4.5:1 на `--dusk` — проверять) |
| `--line` | `#F4A259` | линия горизонта, единственный акцент |

- Акцент `--line` — только для линии, активного состояния и одной главной
  кнопки на экран. Не для заливки крупных плоскостей и не для выделения слов.
- Тема времени суток (этап 3.8) переопределяет эти же токены на
  `[data-time="morning|day|sunset|night"]`. Компоненты цвет напрямую не знают.

## Шрифты

- Дисплей: **Geologica** (`@fontsource-variable/geologica`): оси `wght`,
  `slnt`, `SHRP`. Иерархия — весом и остротой, а не только кеглем.
- Текст: **Golos Text** (`@fontsource/golos-text`).
- Prata удаляется.
- Шкала: display `clamp(4rem, 13vw, 12rem)` / 0.86; h2 `clamp(2.4rem, 6vw, 5rem)` / 0.95;
  h3 `1.5rem`; текст `1.0625rem` / 1.6; подписи не меньше `0.875rem`.
- Цифры — `font-variant-numeric: tabular-nums`. Ключевые цифры (26, 180 м,
  3,15 м) — графика: крупный дисплейный кегль и привязка к линии.

## Отступы

Шкала, кратная 8: `--s1` 8, `--s2` 16, `--s3` 24, `--s4` 40, `--s5` 64,
`--s6` 104, `--s7` 168 px. Между секциями — `--s6`…`--s7`. Поля страницы —
`clamp(16px, 5vw, 64px)`. Только значения шкалы, без случайных `22px`.

## Движение

- Lenis (плавный скролл) + GSAP ScrollTrigger. Других анимационных библиотек нет.
- Характер «чертёжный»: линии прочерчиваются (`stroke-dashoffset`), блоки
  встают на сетку, маски открываются горизонтально вдоль линии.
- Длительности: микро 150–250 мс, появления 500–800 мс, ease
  `cubic-bezier(.2,.7,.1,1)`. Привязанное к скроллу — `scrub`, без таймеров.
- Анимируем только `transform`, `opacity`, `clip-path`, `stroke-dashoffset`.
- `prefers-reduced-motion: reduce` → Lenis выключен, scrub-сцены показывают
  конечное состояние, линия статична. Контент обязан читаться без JS-анимаций.
- Телефон: hover → тап, перетаскивание → свайп. Фишки адаптируются, а не
  отключаются.

## Каждая прокрутка удивляет (требование Георгия, 2026-10-26)

У каждой секции — своё необычное движение по скроллу, которого нет в других
секциях. Тихое «появление снизу» само по себе не считается анимацией. Карта:

| Секция | Что происходит при прокрутке |
|---|---|
| Первый экран | WebGL-вода отступает, текст выходит мокрым, капли срываются по физике (сделано) |
| Вид из окна | камера поднимается по этажам: панорама уходит вниз, горизонт опускается, слой тумана расходится |
| Интерьеры | закреплённый экран; кадры раздвигаются из щели, как панорамные двери, прежний уходит в глубину |
| Шахматка | фасад собирается из этажей, падающих сверху; наведение подсвечивает этаж и свободные квартиры |
| Ипотека | цифры прокручиваются как счётчик, график платежа рисуется кривой прилива |
| Район | настоящая карта (OSM + рельеф): камера от дома отъезжает к городу, маршруты идут по реальным дорогам |
| Стройка | дом с первого экрана растёт монолитом из чертежа фасада, леса и кран поднимаются вместе с ним |
| Запись | шаги сменяются волной; успех — волна накрывает форму и отступает с текстом ответа |
| Подвал | огромное слово «ОТЛИВ», буквы наполняются водой по мере подхода к концу страницы |

Капли и вода — по реальной физике: плёнка сбегает за доли секунды, капли
срываются с ускорением, повторно капают с растущей паузой.

## Композиции — чередовать

Допустимые типы: полноэкранное фото · текст на воздухе · асимметричная сетка ·
горизонтальный скролл · интерактивный инструмент. Две соседние секции одного
типа запрещены. Порядок главной фиксируется в этапе 3 и записывается сюда.

## Запреты

1. Одинаковые композиции секций подряд.
2. Повтор навигации внутри секций (стрелки «назад/вперёд», дублирующие кнопки
   «Все квартиры» в каждой секции).
3. Мелкий или низкоконтрастный текст: меньше 14 px или ниже WCAG AA.
4. Обычные таблицы там, где возможен интерактив (шахматка, стройка, ипотека).
   Таблица допустима только как запасной вид «списком» в каталоге и в сравнении.
5. Фото в простых прямоугольниках без маски и движения.
6. Стоковые иконки, «ИИ-градиенты», карточки с тенями, стекло с размытием
   фона, glow-шары. Общие правила портфолио про glow и стекло здесь не действуют.
7. Выделение слов цветом в заголовках, eyebrow с точкой, три колонки статистики,
   шаги «01–04».

## Техника и качество

- Lighthouse на телефоне 90+; изображения WebP/AVIF с `srcset`, `loading="lazy"`
  ниже первого экрана.
- Видимый `:focus-visible` (линия `--line`, 2 px, отступ 3 px), семантика,
  `aria-live` у меняющихся цифр.
- Проверка по `PORTFOLIO/CLAUDE.md` (Local-First): собранный `dist`, скриншот,
  замеры контраста и переполнения на 375 и 1440 px.
- Подвал и формы — по Demo-Site Presentation Rule.
- Новые зависимости — только `lenis`, `gsap`, `@fontsource-variable/geologica`.
  Любую другую согласовывать.
