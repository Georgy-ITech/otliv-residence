# Отлив — сайт ЖК у моря

Концепт-проект: сайт вымышленного жилого комплекса бизнес-класса «Отлив» на мысу у Уссурийского залива, Владивосток. Цены, статусы квартир и ход строительства — демонстрационные, берег на карте стилизован.

**Живой сайт:** https://georgy-itech.github.io/otliv-residence/

## Что внутри

- **Дом на карте.** Первый экран — морская навигационная карта, построенная кодом (поле глубин → изобаты маршевыми квадратами), на ней 3D-дом из кода без готовых моделей. Солнце идёт с прокруткой: тень дома ползёт по промерам, к вечеру зажигаются окна.
- **Выбор этажа на доме.** Наведение на этаж показывает свободные квартиры и цену «от»; клик открывает план этажа со статусами. Тот же выбор — линейкой этажей с клавиатуры.
- **Каталог.** Фильтры по комнатам, цене, площади, этажу и виду, сортировка, режим «шахматка» (194 квартиры), пустое состояние, фильтры в адресной строке.
- **Карточка квартиры.** Планировка в едином масштабе с площадями комнат, схема вида из окна в манере лоции (зависит от этажа и стороны), ипотека и рассрочка, отметки и сравнение до трёх квартир.
- **Район, ход строительства, запись на просмотр** с валидацией и маской телефона.

## Стек

React 19 · TypeScript · Vite 8 · Three.js / React Three Fiber · React Router (хеш) · шрифты Alegreya и Golos Text локально.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, публикация — GitHub Pages через Actions.
